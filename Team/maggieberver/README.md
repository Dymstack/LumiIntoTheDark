## Sobre mí

### Intereses:
Me gusta programar, pero también disfruto organizar un equipo y documentar el proceso de trabajo.

### Experiencia previa:
- Hace un año desarrollé un videojuego web llamado *Star Hunter*.
- He programado sitios simples, como el sitio web de un restaurante y un sistema de selección de asientos de una sala de cine.

### ¿Qué es “diseñar un videojuego” para mí?
Significa diseñar una experiencia inmersiva y entretenida para los demás.

### ¿Cómo imagino mi rol como diseñador durante el curso?
Quiero mejorar la idea de videojuego que tiene mi equipo para que los usuarios finales disfruten al máximo su tiempo de juego, haciéndolos sentir como si estuvieran dentro de él.

## ¿Quiénes somos?

Somos **Redborn Arts**, un equipo de desarrollo independiente formado este semestre para crear una nueva experiencia en el mundo de los videojuegos. Cada integrante aporta habilidades únicas y diferentes perfiles al equipo. Aunque cada uno tiene su propio rol, compartimos los mismos intereses:

* Experimentar con nuevas tecnologías, mecánicas y procesos creativos.
* Contar historias atractivas a través del arte visual, las interfaces limpias y la interacción del jugador.
* Diseñar experiencias inmersivas, entretenidas y memorables para quienes jueguen nuestro videojuego.
* Aprender juntos, coordinar procesos creativos y documentar cada paso del desarrollo de manera colaborativa.

# Lumi Into The Dark

***Lumi Into The Dark*** es un videojuego 2D de aventura y evasión exclusivo para móviles en orientación vertical, con una perspectiva de vista desde arriba (top-down). El jugador controla a un pez linterna desorientado en la superficie que debe descender hacia las profundidades del océano para regresar a su hogar. La experiencia se centra en el movimiento continuo, la evasión de depredadores y obstáculos, y la gestión de una mecánica de iluminación (linterna) para sobrevivir y explorar en entornos cada vez más oscuros.
